# Zin Eddine Bendaas — Portfolio

A responsive, single-page multilingual portfolio in English, French, Arabic, and German.

## Run locally
Open `index.html` in a modern browser. No build tools or dependencies are required.

## Before publishing
- Replace the GitHub placeholder link with your actual profile.
- Add a professional photo only if desired.
- Add phone number only if you want it public.
- Add screenshots, diagrams, READMEs, and evidence for projects as they become ready.
- Keep skill levels and project status honest; the current copy intentionally distinguishes training and ongoing projects from professional experience.

## Publish
Upload `index.html` to a GitHub repository and enable GitHub Pages, or deploy the folder to Netlify / Cloudflare Pages.
